Day 1 Homelab


1. Configure D1 & D2 as DHCP server for VLAN 10
   D1: .100-.199
   D2: .200-.254

D1 [L3 Switch 15.2 (2019) 	512MB/128KB 	16e/0s]
conf t
  ip dhcp excluded-address 10.2.1.1 10.2.1.99
  ip dhcp excluded-address 10.2.1.200 10.2.1.254
  !
  ip dhcp pool MGMTPOOL 
    network 10.2.1.0 255.255.255.0
    default-router 10.2.1.1
    dns-server 10.2.1.1
    domain-name MGMT.COM
    end


D2 [L3 Switch 15.2 (2019) 	512MB/128KB 	16e/0s]
conf t
  ip dhcp excluded-address 10.2.1.1 10.2.1.199
  !
  ip dhcp pool MGMTPOOL 
    network 10.2.1.0 255.255.255.0
    default-router 10.2.1.2
    dns-server 10.2.1.2
    domain-name MGMT.COM
    end
  
2. Configure P1 & P1 as DHCP Clients for their VLANs


A1 [L3 Switch 15.2 (2019) 	512MB/128KB 	16e/0s]
conf t
   interface e0/0
      switchport mode access
      switchport access vlan 10
      end

A2 [L3 Switch 15.2 (2019) 	512MB/128KB 	16e/0s]
conf t
   interface e1/0
      switchport mode access
      switchport access vlan 10
      end

P1 [Router 15.7 (2018) 	512MB/128KB 	16e/0s]
conf t
   interface e0/0
   no shut
   ip add dhcp
   end

P2 [Router 15.7 (2018) 	512MB/128KB 	16e/0s]
conf t
   interface e1/0
   no shut
   ip add dhcp
   end
